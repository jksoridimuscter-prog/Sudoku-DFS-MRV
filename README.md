# Sudoku Solver Using DFS Backtracking and MRV

## 1. Project Overview

This project implements and compares two search strategies for solving 4×4 and 6×6 Sudoku puzzles:

- **DFS with Basic Backtracking:** Selects empty cells in a fixed order.
- **DFS with MRV Heuristic:** Selects the empty cell with the fewest remaining legal values.

The main objective is to compare the performance of these algorithms in terms of execution time, expanded nodes, and backtracking count.

## 2. Technologies

- Programming Language: Python 3
- Development Environment: Visual Studio Code
- Libraries: Python Standard Library

## 3. Project Structure

- `sudoku_experiment.py`: Main source code containing both Sudoku-solving algorithms and the experimental procedure.
- `sudoku_results.csv`: Experimental results generated by the program.
- `README.md`: Project description and execution instructions.

## 4. Test Datasets

The experiments use six Sudoku test cases:

| Test Case | Grid Size | Difficulty |
|---|---|---|
| S4-E | 4×4 | Easy |
| S4-M | 4×4 | Medium |
| S4-H | 4×4 | Hard |
| S6-E | 6×6 | Easy |
| S6-M | 6×6 | Medium |
| S6-H | 6×6 | Hard |

## 5. How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Run the following command:

```bash
python sudoku_experiment.py
```

5. The program executes both algorithms on the six Sudoku test cases.
6. The experimental results are exported to `sudoku_results.csv`.

## 6. Experimental Configuration

- Sudoku sizes: 4×4 and 6×6.
- Difficulty levels: Easy, Medium, and Hard.
- Number of runs: 20 per test case and algorithm.

## 7. Evaluation Metrics

The algorithms are evaluated using three metrics:

- **Execution Time (ms):** Time required to find a solution.
- **Expanded Nodes:** Number of incomplete states processed during the search.
- **Backtracking Count:** Number of assignments undone after unsuccessful search branches.

## 8. Reproducibility

The Sudoku test cases, candidate-value ordering, and MRV tie-breaking strategy are deterministic.

The search results, expanded-node counts, and backtracking counts should remain consistent when using the same source code and input data.

Execution-time measurements may vary depending on the computer hardware and runtime environment.

## 9. Repository

This repository contains the source code and experimental results for the study of DFS Backtracking and MRV Heuristic in solving Sudoku puzzles.
